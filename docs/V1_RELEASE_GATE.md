# Критерии стабильного v1.0.0

Основная ветка `main` объединяет работу и автоматически выпускает проверенные пакеты. До выполнения критериев версия пакета имеет суффикс `-rc.1`.

1. На публикуемом SHA проходят fmt/clippy/tests, metadata gate, frontend build/tests и нативные сборки всех заявленных архитектур.
2. Каждый встроенный профиль принимается настоящим bundled engine, проходят циклы Start/Stop, отклонение повторного Start и crash rollback на каждой ОС.
3. На установленных приложениях проверены непривилегированный GUI, системное подтверждение прав, отмена запроса, выход, обновление и удаление.
4. Проверено прохождение реального трафика и восстановление связи в целевых сетях. Ограничения платформ документированы.
5. Определена лицензия собственного кода, сохранены обязательные лицензии и исходники/инструкции перелинковки сторонних библиотек.
6. Пакеты опубликованы с контрольными суммами и привязкой к commit SHA. Статус подписей/Apple notarization указан явно.

Тег `v1.0.0` означает выполнение этих критериев, а не только успешную компиляцию. Кандидаты публикуются как Pre-release.
