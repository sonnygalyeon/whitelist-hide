## Границы проверки

DOM-тест выполняет код интерфейса с имитацией нативного IPC: исходное состояние, прогресс, подключение, остановку, неудачный поиск и восстановление. Нативный smoke проверяет реальные helper, движок и системные ресурсы на одноразовых CI runner'ах. Эти проверки не заменяют проверку установленного GUI и системных диалогов на пользовательском компьютере.

Работа обхода на провайдерах РФ, воспроизведение `googlevideo`, QUIC, WebSocket и голос Discord здесь не проверялись. Автоматический сетевой тест приложения подтверждает только HTTPS/API/CDN по IPv4, что явно указано в интерфейсе. Установщики не подписаны сертификатом издателя, Apple notarization не настроена.

Минимальная версия Rust — 1.88 по требованиям закреплённых зависимостей HTTPS-клиента. Для разработки рекомендуется stable Rust.
