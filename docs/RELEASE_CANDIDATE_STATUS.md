# Release candidate 1.0.0-rc.3 — исправление macOS

rc.3 добавляет ad-hoc подпись macOS приложения и всех трёх executable, проверку уже упакованного DMG, подписи и запуска скопированного GUI. Публикация выполняется после успешных нативных проверок четырёх сборок. [Установка и диагностика macOS](MACOS_INSTALL.md).

Исторические результаты rc.2 сохранены в [AUTO_STRATEGY_CHECKS.md](AUTO_STRATEGY_CHECKS.md). Они подтверждали сборки, движки и SHA-256 файлов, но **не подпись приложения macOS**; rc.2 может вызывать сообщение «повреждено» на Apple Silicon.

## Реализовано

- Desktop GUI Windows/macOS/Linux, тёмно-зелёная тема, шесть профилей и автоподбор для РФ, журнал, сохранение отчёта, восстановление и остановка при выходе.
- Протокольные правила HTTP/TLS, QUIC и Discord/STUN с адаптированными методами Flowseal, подтверждением HTTPS и локальным кэшем для сети.
- Нативный запрос прав через UAC, macOS authorization и polkit; GUI остаётся непривилегированным.
- Windows winws2 получает Lua-параметры; оба Lua-файла поставляются и проверяются вместе с DLL/драйвером.
- Linux nfqws строится со статическими библиотеками Netfilter из архивов с фиксированными SHA-256.
- macOS anchor находится в исполняемой иерархии `com.apple/*`; нестандартный root ruleset отклоняется без его перезаписи.
- Watchdog проверяет процесс/ресурс и публикует доступный GUI heartbeat. После 15 секунд без обновления статус становится неопределённым.
- Операции helper сериализованы файловой блокировкой; watchdog привязан к своей сессии.
- Dependency lockfiles фиксируют зависимости, включая HTTPS-клиент проверок и блокировки helper.

## Проверки

29 сентября 2026 [CI](https://github.com/sonnygalyeon/whitelist-hide/actions/runs/36544420556) и [release-desktop](https://github.com/sonnygalyeon/whitelist-hide/actions/runs/36544420476) прошли на **точном commit SHA** релиза. Проверены Rust tests/fmt/clippy, frontend tests/build на трёх ОС, Tauri, упаковка и метаданные выпуска.

Workflow проверяет реальные параметры каждого профиля через `--dry-run`, затем на одноразовом runner выполняет запуск/остановку всех шести профилей, отклонение повторного запуска и rollback после принудительного завершения движка. Только успешный полный workflow может публиковать пакеты кандидата. Перед открытием релиза сверяются размеры и SHA-256 всех установщиков и файла контрольных сумм.

Сценарий smoke не подтверждает доступность YouTube/Discord в сети пользователя, качество звонка или прохождение трафика через конкретное оборудование провайдера.

## Ещё требуется для стабильного выпуска

- Проверка установленного GUI и системных диалогов подтверждения на пользовательских Windows/macOS/Linux.
- Проверка трафика/сервисов в целевой сети, сна/пробуждения и смены сети.
- Проверка обновления и удаления установленных пакетов при активной сессии.
- Решение владельца о лицензии собственного кода и политике подписи установщиков.

Android/iOS отсутствуют. macOS backend работает с IPv4. Нет автостарта и GUI-редактора списков. Автоподбор проверяет HTTPS/API/CDN по IPv4; видео, QUIC, WebSocket и голос Discord требуют отдельной проверки в целевой сети. Не выдавать кандидат за универсально проверенный стабильный релиз.
